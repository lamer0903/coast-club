# Coast Club

디바의 핑크색 카트로 부산 해안과 모래언덕을 달리는 Canvas 2D 카트 레이싱 게임입니다. 설치나 빌드 없이 index.html을 열거나 이 폴더에서 `python -m http.server 8091`을 실행합니다.

## 로컬 폴더 삭제 후 다시 실행하기

실행 코드와 캐릭터·배경 이미지 7개가 모두 이 저장소에 포함되어 있습니다. 이전 프로젝트 폴더, 이미지 생성 도구, API 키, 환경 변수, npm 패키지 설치는 필요하지 않습니다.

1. Git이 설치된 터미널에서 원하는 상위 폴더로 이동한 뒤 복제합니다.

   ```sh
   git clone https://github.com/lamer0903/coast-club.git
   cd coast-club
   ```

   Git이 없다면 GitHub의 **Code → Download ZIP**으로 받아 압축을 풀어도 됩니다. 비공개 저장소인 경우 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다.

2. 가장 간단한 실행 방법은 `index.html`을 Edge 또는 Chrome에서 여는 것입니다. Windows에서는 파일을 더블클릭하면 됩니다. WSL이나 tmux는 필수가 아닙니다.

3. 로컬 서버로 실행하려면 Python 3가 설치된 환경에서 다음 명령을 실행합니다.

   ```sh
   python -m http.server 8091 --bind 127.0.0.1
   ```

   Ubuntu/WSL에서는 `python` 대신 `python3`을 사용할 수 있습니다. 브라우저에서 <http://127.0.0.1:8091>에 접속하세요. 서버 종료는 `Ctrl+C`입니다. 포트가 사용 중이면 `8092` 등 다른 포트를 지정하고 접속 주소도 맞춰 주세요.

4. **LET’S RACE**로 시작하고 **SOUND ON**을 눌러 소리를 켭니다.

인터넷 연결 없이도 게임과 포함된 이미지는 실행됩니다. Google Fonts를 불러오지 못하면 시스템 글꼴을 사용합니다. 최고기록은 해당 브라우저의 `localStorage`에 저장되므로 새 컴퓨터·브라우저·접속 주소로는 자동 이전되지 않습니다. 소스 수정 후에는 커밋과 푸시를 마쳐야 그 변경도 다시 받을 수 있습니다.

개발 검증을 다시 실행하려면 Node.js 24 이상을 설치한 뒤 아래 `검증` 항목의 명령을 사용하세요. Node.js와 Python은 `index.html`을 직접 열어 플레이할 때는 필요하지 않습니다.

## 조작

- ↑ / W 가속, ↓ / S 브레이크, ← → / A D 방향
- 코너 방향 + Shift로 드리프트 시작. 방향키를 잠시 놓아도 유지됩니다.
- Shift를 놓으면 미니 터보: 파랑 0.65초, 주황 1.3초, 분홍 2.1초
- 반대 방향 조향, 도로 이탈, 저속, 브레이크는 드리프트를 취소합니다.
- Space: 부스터 30 소모. 다시 사용하려면 놓았다가 누르세요.
- 부스트는 초반에 강하게 가속하고 종료 후 약 0.7초 동안 순항 속도로 돌아옵니다. 부스트 중에도 브레이크가 우선합니다.
- 좌우 입력과 반대 조향은 빠르게 반응하고, 손을 놓으면 짧은 관성 뒤 접지력을 회복합니다. 부스트 중에는 조향이 조금 무거워집니다.
- 터치: 자동 가속, 왼쪽 조향, 오른쪽 DRIFT / BOOST / BRAKE
- Esc 또는 정지 버튼: 카운트다운·레이스 정지 및 재개
- SOUND ON: 불규칙한 연소 맥동 PCM을 재생하는 배기음. 가속·가상 6단 변속에 반응하고, 노면·타이어 마찰음·부스터 분사음은 별도 레이어입니다. 지속적인 사인파 저음과 전자 비프음은 제거했습니다. 브라우저에서 합성한 사운드이며 실제 자동차나 오버워치 원본 녹음은 아닙니다.

라이벌 3명과 구간별 코너가 있는 해안 코스를 3바퀴 달립니다. 조향 없이 달리면 모래에서 감속합니다. 코너 탈출 전에 드리프트를 놓아 터보를 활용하세요.

완주 시간, 베스트 랩, 이전 완주 대비 차이를 표시합니다. 최고기록은 브라우저 localStorage에 저장하며 브라우저·접속 주소별로 구분됩니다. 저장이 차단돼도 플레이할 수 있고 결과 화면에 저장 불가를 알립니다.

## 그래픽

- 왼쪽 하단 미니맵: 실제 커브 데이터를 이용한 한 바퀴 경로 개요와 출발(S)·도착(F), 디바(분홍)·트레이서(주황)·겐지(초록)·리퍼(밝은 회색)의 진행 위치를 표시합니다. 모바일에서는 작게 표시합니다.
- 실사풍 디바 카트·야자수 투명 이미지와 부산 해안 파노라마. 코너에 따라 배경이 움직이고 카트는 조향·드리프트에 맞춰 기울어집니다.
- 사진풍 에셋과 기존 Canvas 지형을 조합한 2.5D 표현이며, 실시간 3D 모델 렌더링은 아닙니다. 경쟁자는 트레이서·겐지·리퍼이며 각각 전용 카트 이미지와 이름표를 사용합니다.
- 금속 리어윙·배기구·회전하는 타이어 홈, 드리프트 연기와 불꽃
- 원근 아스팔트 입자·코너 고무 자국·도로 경계선, 해안 난간과 등대 랜드마크
- 수심별 바다 색상, 햇빛 반사, 움직이는 해안 포말과 원근 잔물결
- 불규칙한 간격·폭·높이의 비대칭 모래언덕, 경사면의 명암과 미세 바람결·입자·식생 (지형은 코스에 고정)
- 일반 화면에서도 CSS 크기 대비 가로·세로 3배 렌더링(픽셀 수 9배). 예: 1200×580 → 3600×1740. 1600만 픽셀을 넘는 큰 화면에서는 배율을 자동 제한합니다.
- 이미지 로딩 중 또는 실패 시 기본 그래픽으로 플레이할 수 있고, 실패 안내와 새로고침 방법을 표시합니다.
- 시스템의 동작 줄이기 설정에서는 카메라 흔들림·회전·부스트 시야 변화와 속도선을 끕니다.

## 검증

- `node check.cjs`: 주행·충돌 기본 검증
- `node race-check.cjs`: 가속 / 조향 / 드리프트 비교, 충전 취소, 랩 시간, 투영 좌표
- `node browser-check.cjs`: DOM/Canvas 모형으로 입력·정지·완주·재시작 검증
- `node handling-check.cjs`: 부스트 초반 가속·종료 감속, 제동 우선, 조향 반응과 30/60/120 Hz 일관성 검증

## 구성

- track.js: 공통 코스, 곡률, 화면 투영
- engine.js: 주행·AI·충돌·랩 기록
- game.js: 렌더링, 입력, UI, 소리, 기록 저장
- style.css: 반응형 화면과 터치 조작

외부 게임 라이브러리는 없습니다. 생성 이미지들은 `assets/`에 포함되어 로컬에서도 불러옵니다. 웹 폰트는 온라인에서 적용됩니다.
